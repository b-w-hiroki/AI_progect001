# 実プロダクトでの学習・検証記録

小さな機能一つを対象に、学習を実装と検証につなげます。これは記録テンプレートであり、実施済みの実験や費用削減の証明ではありません。

1. 対象のリポジトリ・基準SHA・利用者が困る場面を決める。
2. 再現手順・期待結果・変更しない範囲を先に書く。
3. LEARNING_AWS.mdや該当Labで必要な知識を確認し、製品側で最小修正する。
4. 同じ入力条件で変更前後を確認。成功・失敗・未実施を区別する。
5. 時間・AI利用料・クラウド費用を実測で記録し、採用・保留・棄却を決める。

## 記録用テンプレート

- 対象リポジトリ / 基準SHA / 変更SHA:
- 困りごと / 再現手順:
- 学ぶ内容 / 参照資料:
- Done条件 / 変更しない範囲:
- 検証コマンド / 結果 / 未検証:
- 作業時間（計測範囲も記載）:
- AI・クラウド費用（通貨と期間。不明なら不明）:
- 採否 / 理由 / 次の一手:
- PR / CI / 実行記録のリンク:

共通開発基準は [studio-playbook](https://github.com/b-w-hiroki/studio-playbook)、研究・実行記録は [ai-worklog](https://github.com/b-w-hiroki/ai-worklog) を参照します。規約の複製や自動同期ではありません。製品固有の仕様と現行コードを照合してください。

AWSリソース作成や有料API呼出しは承認された範囲内でのみ行います。認証情報・顧客データは記録しません。この手順の追加では実デプロイや有料処理を行っていません。
