# Lab の完了証拠

Lab ごとの実行記録に次の項目をコピーして記入します。未実施は未実施のまま残し、CI 成功で埋めないでください。アカウント ID・認証情報・実ユーザーデータは記録に含めません。

## 実行前

- Lab ID と対象コミット:
- 対象リージョンと実行予定日:
- 作成予定リソースと課金要因:
- 自分で承認した費用上限（金額・通貨・期間）:
- 上限到達を知る方法と停止の判断者:
- 終了予定時刻と削除担当:
- Lab の README にある作成・削除手順を確認したか:

予算通知は支出を自動で止める上限ではありません。無料利用枠を前提にせず、価格・呼び出し回数・実行時間・残存ストレージを確認してください。

## 機械検証

- `terraform fmt -check` と `terraform validate` の結果・時刻:
- `atlas check <Lab ID>` の結果・時刻:
- 対象 SHA の CI リンクと実行した job:
- 未実行のチェックと理由:

構文検証は AWS に作成された資源の正常動作を保証しません。認証や費用が必要な検証は、承認した環境と上限の範囲で別に行います。

## 動作証拠

- 正常系の入力、期待結果、実際の結果:
- 異常系（欠損・権限不足・過大入力など）の期待結果と実際の結果:
- ログまたはスクリーンショットの保管先（秘密情報を除く）:
- 残った問題と次の対応:

## 終了と削除

- 自分が管理している専用 Lab の作業ディレクトリ・workspace・state と対象アカウントを確認:
- 共有資源や業務用資源が混ざっていないことを確認:
- Lab README の削除手順と削除予定一覧を確認した日:
- 承認して実行した削除の結果:
- 追加で残ったログ・バケット・レイヤー等の有無と扱い:
- 時間差で更新される利用明細の確認予定:

この記録は `apply` / `destroy` の実行許可ではありません。共有資源や不明な state に対して削除しないでください。削除コマンドの終了コードだけで費用ゼロと断定しません。
